How to create custom middleware
    inside Middleware folder 
    create middleware file with respective name
    inside that we write middleware logic
    middleware function have 4 parameters 
      (err,req,res,next) =>{
          err -> previous step
          req -> request data
          res -> response from previous step
          next -> to execute next process after this middleware process is done
      } 
    middleware runs in this sequence 
    request -> middleware (can be multiple) -> controller (actual code logic) -> response 
    to use middleware in our app we write 
    app.use(customMiddleware)
